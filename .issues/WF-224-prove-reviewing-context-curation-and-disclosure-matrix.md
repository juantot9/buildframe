## Acceptance

- [ ] The matrix covers file/directory/range rules, default ignored exclusion, stable prefix exclusion, recreation, rename, direct override, equal-specificity replacement, overlap, and lossless ordering.
- [ ] Saved/unsaved Editor and concrete Artifact occurrences cover equal/different bytes, nominal-path conflicts, removal, external movement, restart, and no implicit refresh or ambient Presence.
- [ ] Snapshot cases cover complete/incomplete capture, unavailable/over-limit/binary/unrenderable items, retained-byte eviction, current/stale/unverified, pin/exclude/retry, unchanged reuse, context-only successor, and combined Change Set/context movement.
- [ ] Route cases cover every representation and limitation, exact Preview/Delta bytes and ordering, destination and Capability movement, sensitive acknowledgment reuse/invalidation, blocker versus gate, and Adapter payload confinement.
- [ ] Budget cases cover exact proposed counts, no telemetry, fresh matching telemetry, stale model/session generations, compaction, Attachment loss, and restoration without false percentages or payload mutation.
- [ ] Fault/mutation probes trip if selection/capture/representation/consent collapse, excluded movement stales a Snapshot, an immutable contribution refreshes, unknown scope is acknowledged, ambient content enters, or an effect precedes commit.
- [ ] Canonical verification, all four compiled risk probes, dependency/package seams, dogfood, and `git diff --check` pass on Node 26.5.1 / pnpm 11.20.0 with unrelated work unstaged.

## Constraints
