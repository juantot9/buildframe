Corroborate semantic outcomes through bounded fixture-owned metadata after the human run: no command for the saved continuation endpoint, exactly one transition for accepted current HEAD, immutable historical identity, preserved target-change safety, and no replay.
- A failed or confusing case is not reworded into acceptance. Stop, create and push one focused child at its owning private Application or Workspace seam, repair it there, and rerun the affected human case before closing this child.
- Remove every disposable fixture, runtime/socket, HOME, configuration, log, and helper after accepted evidence is recorded. Confirm no process remains, `git diff --check` passes, and only WF-147/WF-140 issue records changed. Preserve legacy/user data, package Interfaces, P54 scope, and the unrelated root `package.json` bump.
